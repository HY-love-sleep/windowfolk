# English translations for the Windowfolk submission

This document translates the Chinese application text visible in the [2:55 demonstration](https://www.youtube.com/watch?v=8utV-wg0Fo4), gallery images, and downloadable macOS test build. The video has English explanatory titles and no spoken narration. The recorded application uses Chinese; those explanations do not replace the detailed translations below.

For installation and a reproducible test sequence, use the [English testing guide](README.en.md). The repository's default [README](../README.md), [submission description](submission.md), [Kiro usage write-up](kiro-usage.md), and [current validation report](validation/2026-11-20/report.md) are in English. [README.zh-CN.md](../README.zh-CN.md) preserves the Chinese README.

At 2:25–2:32, the video shows the November 20 diaries, headed by each resident's name. They concatenate sentences from recorded events, including repeated actions during the demonstration. ## Optional AI settings and disclosure

AI generation is disabled by default and was not used in the video. Judges need no API key, subscription, or account. The settings panel shown at 2:32–2:37 translates as follows.

| Original | English |
| --- | --- |
| LLM 服务 | LLM service |
| 服务地址 | Service endpoint |
| 模型名 | Model name |
| API Key | API key (stored in macOS Keychain) |
| 日记使用 LLM | Use an LLM for diaries |
| 小心思 | Resident thoughts |
| 需补全：服务地址、模型名、API Key | Complete these fields: service endpoint, model name, API key |
| 地址格式无效：需以 http:// 或 https:// 开头并包含主机名 | Invalid endpoint: use http:// or https:// and include a hostname. |
| 钥匙串读写失败，API Key 未能保存或读取，已按空处理 | Keychain access failed. The API key could not be saved or read and is treated as empty. |
| 打开「日记使用 LLM」前请确认 / 打开「小心思」前请确认 | Confirm before enabling “Use an LLM for diaries” / “Resident thoughts.” |
| 发送给 LLM 服务的内容只有：居民名字、事件类型、事件时间、日期、物件种类、心愿种类、心愿状态、追逐结局、花的生长阶段。不包含窗口标题和应用名称。 | Only resident names, event types, event times, dates, object types, wish types, wish states, chase outcomes, and flower growth stages are sent to the LLM service. Window titles and application names are not included. |
| 确认 / 取消 | Confirm / Cancel |
