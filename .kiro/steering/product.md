# 窗间 · Windowfolk

产品完整说明见 `docs/concept.md`；开发边界与交接见 `AGENTS.md`。

- 产品：把应用窗口布局变成地形，让小居民通过用户建立的通路搬运、拜访与布置住所。
- 循环：改变布局 → 连接通路 → 居民行动 → 留下变化。
- 首个验证：两个居民、两个平台、一座桥、一次花盆搬运及保存恢复。
- 优先平台：macOS。本地客户端；VPS、账号和模型 API 均非必要。
- 尚未选栈，也未实现任何功能。先比较最小技术路线，获所有者确认后实现。
- 重点验证窗口变化、遮挡、路径失效、鼠标穿透、焦点和资源占用。
- 不默认读取屏幕内容或键盘输入，不操作真实文件和其他应用。
- 不把常见桌宠能力当作原创；复用前核查代码和素材许可。

此文件是 Hermes 初始化的产品上下文，不是 Kiro 已完成开发的证明。Specs、测试结论和使用说明应随真实开发形成。
